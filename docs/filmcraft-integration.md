# FilmCraft 연결: 범위와 인수 기준

상태: 계획. 2026-11-03에 기존 손잡고 연결에서 읽기 기능만 확인했습니다.

## 책임 경계

| 구성 | 책임 |
| --- | --- |
| Story Studio | 이야기·만화·영상 계획, 편집안 미리보기, 실행 요청과 결과 표시 |
| 손잡고 | 로그인 사용자·허용된 연결·작업 전달과 상태 조회 |
| FilmCraft | 실제 미디어·시퀀스·자막·러프컷 실행 |

이야기 원본과 만화는 FilmCraft의 편집 결과로 자동 변경하지 않습니다. ShotPlan의 원본 판과 편집 대상·실행 결과를 연결해 추적합니다. 새 DB·큐·병렬 인증 체계는 선행해서 만들지 않습니다.

## 확인된 것과 남은 것

- `com.sonjapgo.filmcraft.read`의 명령 목록·프로젝트·문서·시퀀스·프레임 조회 계약이 존재합니다.
- 실제 명령 목록 조회가 성공했습니다. 자막 생성·수정·시간 조정·import/export 명령이 표시됩니다.
- 이 목록은 편집 실행 권한을 부여하지 않습니다. 공개된 원격 계약은 조회 전용입니다.
- 러프컷은 사용자가 현재 앱에서 진행 가능하다고 알려준 기능이며, 이 저장소에서 실제 러프컷 실행은 검증하지 않았습니다.
- 현재 Sites 도구 목록에서 앱 연동 허용 여부 조회 기능을 찾지 못했습니다. 직접 커넥터 연결은 미확인입니다.

## 첫 연결의 인수 기준

1. 로그인한 사용자의 연결과 FilmCraft 대상 프로젝트·시퀀스를 조회합니다.
2. ShotPlan에서 자막·소스 범위·순서를 포함한 편집안을 미리 봅니다. 실제 미디어가 없는 계획은 실행하지 않습니다.
3. 사용자가 대상과 편집안을 확인하고 실행을 누른 경우에만 기존 허용 경로로 전달합니다.
4. 중복 클릭·시간 초과에 같은 편집을 자동 재실행하지 않습니다.
5. 자막·러프컷 적용 결과를 다시 조회하고 성공·실패·미확인을 구분합니다.
6. 원본 보존·되돌리기 경계는 기존 FilmCraft 실행 계약에 맞춰 확인합니다.

기능 조회 → 자막 1건 → 러프컷 1건 순서로 연결을 검증합니다. 구현되지 않은 버튼이나 모의 성공 메시지로 대체하지 않습니다.
